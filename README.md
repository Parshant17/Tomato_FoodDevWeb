# 🍅 Tomato – Food Delivery Platform

**Tomato** is a modern, responsive food delivery web application inspired by Zomato. It offers a smooth user experience with multiple functional pages, a shopping cart feature, and elegant UI built using **ReactJS**, **HTML**, and **CSS**.

---

## 🚀 Features

- 🏠 **Home Page** – Showcases banners, categories, and featured restaurants
- 🍽️ **Menu Page** – Displays food items with price and add-to-cart functionality
- 🛒 **Shopping Cart** – View added items, update quantities, and proceed to checkout
- ℹ️ **About Us** – Information about the platform and team
- 📞 **Contact Us** – Contact form for user feedback or support
- ✅ **Responsive Design** – Works seamlessly on mobile, tablet, and desktop

---

## 🛠️ Tech Stack

- **Frontend**: ReactJS, HTML5, CSS3
- **Routing**: React Router DOM
- **State Management**: React Hooks (`useState`, `useEffect`)
- **Styling**: Custom CSS and Flexbox/Grid for layout
